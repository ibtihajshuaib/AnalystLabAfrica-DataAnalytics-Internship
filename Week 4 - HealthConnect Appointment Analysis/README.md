# Week 4 – HealthConnect Appointment Attendance and No-Show Analysis

## Project Overview

The project focuses on analysing HealthConnect Clinic appointment data to understand attendance and no-show patterns and identify factors that may be associated with missed appointments.
The Week 4 work establishes the foundation for Week 5, where the proposed KPIs will be calculated and appointment attendance and no-show patterns will be analysed further.

## Key Activities

- Reviewed the dataset and Data Dictionary.
- Conducted an initial data-quality assessment.
- Identified key variables and business questions.
- Proposed relevant KPIs.
- Developed an initial analysis approach.

## Tools

- Power BI
- Power Query

## Deliverables

- Initial Analysis Report
- Week 4 Project Summary
- Power BI Data Quality Assessment File
