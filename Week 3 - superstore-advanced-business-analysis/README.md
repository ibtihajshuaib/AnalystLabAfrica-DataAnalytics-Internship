# Week 3 – Advanced Business Analysis & Power BI Dashboard
This project was completed as part of the Data Analytics Internship with AnalystLab Africa. The project builds on the Week 2 Superstore Sales & Performance Analysis by using Microsoft Power BI and DAX to perform advanced business analysis and evaluate sales, profitability, product, customer, regional, discount, and time-based performance.

## Tools
- Power Query
- Microsoft Power BI
- DAX

## Skills
Advanced Data Analysis | DAX | KPI Development | Data Visualization | Dashboard Design | Sales & Profitability Analysis | Product Analysis | Customer Analysis | Regional Analysis | Discount Analysis | Time-Based Analysis | Business Insights | Business Recommendations

## Project Deliverables
- Interactive Power BI Project File (.pbix)
- Dashboard PDF (.pdf)
- Advanced Business Analysis Report
- Business Insights & Recommendations Report
- DAX Calculations & Measures Documentation
