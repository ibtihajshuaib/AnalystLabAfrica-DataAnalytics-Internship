# Week 5 – HealthConnect Exploratory Data Analysis

This project covers my Week 5 work for the **AnalystLab Africa Data Analytics Internship**.

## Overview

Building on Week 4, I conducted exploratory data analysis on the **HealthConnect Appointment Dataset** to examine appointment attendance, no-shows, and related patterns.

## Key KPIs

- **No-Show Rate:** 48.46%
- **Attendance Rate:** 46.28%
- **Repeat No-Show Rate:** 55.41%
- **Reminder Attendance Rate:** 47.63%

## Work Completed

- Performed data quality checks and preparation.
- Conducted exploratory analysis across relevant variables.
- Created **13 analytical visualisations**.
- Developed and tested a **two-page Power BI dashboard**.
- Documented key findings, assumptions, and limitations.
- Identified opportunities for cross-track collaboration with Data Science.

## Tools

**Power BI | Power Query | DAX**

## Outcome

Week 5 transformed the Week 4 analysis plan into an implemented exploratory analysis and dashboard, providing a foundation for further HealthConnect project development and potential predictive modelling.
