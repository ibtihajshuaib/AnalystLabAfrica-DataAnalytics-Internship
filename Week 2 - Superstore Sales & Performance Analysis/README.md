# WEEK 2 – SUPERSTORE SALES & PERFORMANCE ANALYSIS 

## Project Overview 
This project was completed as part of the Data Analytics Internship with AnalystLab Africa.
The project uses Microsoft Power BI to analyse Superstore sales and profitability performance across regions, customer segments, product categories and individual products.
